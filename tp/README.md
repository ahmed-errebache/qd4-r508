# Travaux pratiques — R5.08

Un dossier par TP, nommé `tpNN-sujet`.

Chaque projet Spring Boot est autonome : son `pom.xml`, son `mvnw`, ses sources.
Il se lance depuis son dossier :

```bash
cd tpNN-sujet
./mvnw spring-boot:run
```
